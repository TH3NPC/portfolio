No paper. Just receipts.

I'm Yakob, 20, a software and hardware engineer in Addis Ababa. Started frying components at 12 and never stopped. No degree, not waiting for one.

I work both ends of the stack — firmware on ESP32, PIC and Arduino, PCB layout in KiCad, React and Node on top, Python to glue it together. Control systems, ERP dashboards, websites, custom hardware. Different syntax, same logic.

What I provide: projects on request. You describe the machine or the system — I deliver it working. That's the whole job.
